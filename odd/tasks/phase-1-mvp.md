# Feature: phase-1-mvp — Idle RPG pixel art (Godot 4) base MVP
Monorepo `/client` (Godot 4.7.2, static-typed GDScript, GUT headless) + `/server` (deferred to phase 2).
Goal: hero runs and auto-attacks waves + timed boss, gold drops, ATK upgrade raises damage, GUT suite green headless.

## Specs

- S1 Monorepo: "`/client`: Proyecto completo de Godot Engine 4" / "`/server`: Backend ligero" / "Archivo `.gitignore` estricto que ignora `.godot/`, archivos temporales y builds."
- S2 Language: "Todo el código del juego debe escribirse en **GDScript tipado estático**".
- S3 Tests: "se utilizará **GUT (Godot Unit Testing)** ejecutado en modo headless desde terminal (`godot --headless -s addons/gut/gut_cmdln.gd`). Debes escribir pruebas unitarias para cada lógica antes de considerarla terminada."
- S4 Big numbers: user answer "si numeros grandes" → custom immutable `BigNumber` (mantissa float + exponent int) used by the whole economy and combat; values must go beyond 1e308.
- S5 Art: "no tengo sprites usa alguno existende de la comunidad o algo por el estilo para usarlo como MVP" → CC0 community pixel-art packs, credited in `client/assets/CREDITS.md`.
- S6 Core loop: "Scroll lateral infinito con fondos parallax en pixel art." / "El personaje corre y ejecuta ataques básicos cuerpo a cuerpo de forma automática contra oleadas continuas de enemigos y jefes con temporizador." / "Recolección de oro, gemas y experiencia para subir estadísticas planas (Ataque, % Crítico, Daño Crítico, Velocidad, Vida)."
- S7 Screens: "Configuración de `window/size/viewport` y anclaje de interfaz para convivir entre el formato vertical natural en móviles y el formato apaisado/centrado con paneles laterales en PC." Approved design: viewport 720x1280, stretch canvas_items/expand, `.pc` window override 1600x900, battle SubViewport 360x192 integer-scaled, LayoutRoot switches portrait/landscape by aspect, safe area margins.
- S8 Phase 1: "Pasos concretos para configurar la escena principal, el spawner de monstruos, el héroe con ataque automático y la suite de pruebas unitarias GUT para el sistema de daño."
- S9 Offline: "Fórmula determinista ($DPS \times \text{Tiempo validado}$) calculada al iniciar sesión" → pure function; negative elapsed → 0; capped.
- S10 MCP: "Utilizaremos **Godot MCP Toolkit** (puente `@npgamedev/godot-mcp-server`)." Plugin `addons/godot_mcp_toolkit` v1.1.1; server via `npx -y @npgamedev/godot-mcp-server`.
- S11 Architecture (approved plan): pure logic in `client/core/` (RefCounted, no Nodes/autoloads); dependency direction main/ui → systems → entities → components → core; EventBus only for cross-system signals.
